# `config/` — конфигурация эксперимента

Превращает YAML или JSON конфигурации запуска в `ExperimentConfig`. Что писать в
конфигурации и за что отвечает каждый файл в `configs/` — в
[configs/README.md](../../../configs/README.md).

| Файл                   | За что отвечает                                                                                                                                                                              |
|------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `experiment_config.py` | `ExperimentConfig` (имя, зерно, папка вывода, модель, набор, показатели) и `ComponentConfig` (`type` + `parameters`); развёртывание `per_class: true` в отдельный показатель на каждый класс |
| `loader.py`            | чтение файла YAML/JSON, цепочка `extends`, пути относительно файла, где они написаны; `ConfigError`                                                                                          |

Правила чтения:

- `extends` сливает только ключи верхнего уровня: локальный ключ заменяет унаследованный
  целиком. Цикл в `extends` — ошибка.
- Параметр считается путём, если его имя — `manifest`, `checkpoint`, `prediction_dir`,
  `environment` или оканчивается на `_path`, `_dir`, `_root`. Такой путь разрешается
  относительно файла, где он написан, `~` раскрывается.
- `output_dir` по умолчанию — `artifacts` рядом с конфигурацией, `seed` по умолчанию — 42.
