# `visualization/` — рамки на панораме

Команда `pano3dbench draw`, описание — в [docs/visualization.md](../../../docs/visualization.md).

| Файл            | За что отвечает                                                                                                                        |
|-----------------|----------------------------------------------------------------------------------------------------------------------------------------|
| `projection.py` | `Panorama`: точка системы камеры → пиксель равнопромежуточной панорамы, ребро → ломаные с разрывом на шве; рёбра рамки, контур комнаты |
| `overlay.py`    | `overlay_shapes` собирает линии и подписи эталона и предсказания, `render_overlay` рисует их Pillow, `manifest_overlays` — по перечню  |

Проекция и сборка линий — на чистом Python и тестируются без Pillow. Pillow импортируется
только при рисовании; без него команда сообщает, как его поставить (`pano3dbench[viz]`).
