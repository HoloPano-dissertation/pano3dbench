# `datasets/` — примеры и эталон

Загрузчик набора выдаёт по одному `SceneSample`: идентификатор сцены, путь ко входу и
эталонную сцену, если она есть.

| Файл                  | За что отвечает                                                                           |
|-----------------------|-------------------------------------------------------------------------------------------|
| `base.py`             | `DatasetLoader` (итерируется по `SceneSample`) и реестр `DATASET_LOADERS`                 |
| `manifest_dataset.py` | `ManifestDatasetLoader`: читает `manifest.jsonl`; в конфигурации `manifest` или `igibson` |

Одна строка `manifest.jsonl` — одна сцена:

```json
{"sample_id": "house/room/0", "input": "panorama.png", "ground_truth": "gt/0.json", "metadata": {}}
```

`input` и путь к эталону разрешаются относительно самого перечня, вход должен
существовать. `ground_truth` — путь к JSON `SceneOutput`, сам словарь сцены или отсутствует:
тогда показатели, которым нужен эталон, на этой сцене пропускаются.
