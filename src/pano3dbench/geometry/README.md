# `geometry/` — геометрия

Чистая математика: здесь нет чтения конфигураций, запуска моделей и записи отчётов.
Как эти функции используются в показателях — в [metrics/README.md](../metrics/README.md).

| Файл               | За что отвечает                                                                                                               |
|--------------------|-------------------------------------------------------------------------------------------------------------------------------|
| `boxes.py`         | `BoundingBox3D` (по осям) и `OrientedBox3D` (ориентированная): объём, пересечение, `box_iou`, чтение из словаря (`parse_box`) |
| `polygon.py`       | выпуклая оболочка, площадь многоугольника, площадь пересечения двух выпуклых многоугольников на XY                            |
| `point_cloud.py`   | k-d дерево и ближайший сосед, Chamfer и F-score пары облаков, нормировка пары (`canonical`, `unit`)                           |
| `mesh_sampling.py` | равномерная выборка точек с поверхности треугольной сетки                                                                     |

Пересечение ориентированных рамок считается как площадь пересечения их следов на плоскости
XY, умноженная на перекрытие по высоте.
