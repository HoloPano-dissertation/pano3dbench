# `file_formats/` — файлы форм

Чтение и запись геометрических файлов. Здесь только разбор форматов, выборка точек — в
[geometry/](../geometry/README.md), а выбор формата по ссылке на форму предмета —
`load_shape_points` в [metrics/shape.py](../metrics/shape.py).

| Файл             | За что отвечает                                                                                                |
|------------------|----------------------------------------------------------------------------------------------------------------|
| `mesh_files.py`  | PLY (ASCII и binary little-endian) и OBJ → вершины и треугольники; многоугольники режутся веером               |
| `point_files.py` | облака точек: список `[[x, y, z], ...]` из JSON, чтение и запись сырого float32 little-endian (`.f32`, `.bin`) |
