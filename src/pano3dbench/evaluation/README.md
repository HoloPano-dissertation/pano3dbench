# `evaluation/` — ход оценки

| Файл               | За что отвечает                                                                                     |
|--------------------|-----------------------------------------------------------------------------------------------------|
| `evaluator.py`     | `Evaluator.run()`: проходит сцены, считает показатели по сцене и по набору, отдаёт результат записи |
| `aggregation.py`   | `aggregate()`: число сцен, среднее, медиана, 95 % доверительный интервал (`bootstrap_ci`)           |
| `result_writer.py` | `ResultWriter`: пишет `predictions/`, `metrics.jsonl`, `summary.json`, `run.json`, `report.md`      |

`Evaluator.run()` по шагам:

1. Взять все сцены набора и отдать их источнику предсказаний одним списком (пакетному
   раннеру нужен весь набор сразу).
2. Каждое предсказание сразу записать в `predictions/<sample_id>.json`.
3. Посчитать показатели по сцене (`_evaluate_scene`). Показатель, которому нужен эталон,
   на сцене без эталона пропускается; NaN не записывается.
4. Собрать сводку по каждому показателю (`aggregate`), затем посчитать показатели по набору
   (`_evaluate_dataset`) по сценам с эталоном.
5. Записать сводку, происхождение прогона и таблицу.

Смысл чисел и правила NaN — в [metrics/README.md](../metrics/README.md#сводка-по-набору-evaluation)
и [docs/metrics.md](../../../docs/metrics.md).
