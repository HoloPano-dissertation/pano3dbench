# `detection2d/` — 2D-детектирование на панораме

Отдельная от `pano3dbench run` оценка первого звена конвейера: срабатывания 2D-детектора
против COCO-разметки, с учётом шва панорамы. Команда — `pano3dbench detect2d`, смысл
чисел — в [docs/metrics.md](../../../docs/metrics.md#2d-детектирование-на-панораме-pano3dbench-detect2d).

| Файл                   | За что отвечает                                                                                                   |
|------------------------|-------------------------------------------------------------------------------------------------------------------|
| `masks.py`             | `PanoramaMask`: несжатый RLE COCO как отрезки по столбцам, поворот, объединение, IoU; `PanoramaBox` и `box_of`: прямоугольник как наименьшая дуга на цилиндре, IoU через шов |
| `panoramas.py`         | чтение эталона COCO (кадр 1 возвращается в исходную панораму, части экземпляра сливаются) и срабатываний (JSON lines) |
| `average_precision.py` | `AveragePrecision`: сопоставление и накопление как в `pycocotools` (IoU 0.50:0.95, 101 точка полноты, 100 срабатываний на кадр), полнота на шве |
| `evaluate.py`          | `evaluate_detections` для прямоугольников и масок, `run_detection_evaluation` пишет `summary.json` и `report.md`   |

Ядро остаётся на чистом Python: маски не разворачиваются в изображения, пересечение
считается слиянием отрезков RLE.
