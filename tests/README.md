# Тесты

```bash
.venv/bin/python -m pytest -q
```

| Папка           | Что проверяет                                                                                    |
|-----------------|--------------------------------------------------------------------------------------------------|
| `core/`         | ядро: сцены и рамки, показатели, протокол классов, конфигурация и реестры, `Evaluator`, демо     |
| `environments/` | спецификации окружений, сборка venv от начала до конца, правки исходников, веса, скрипт кластера |
| `runners/`      | договор раннера, пакетный режим, перевод вывода DPC, словари рамок                               |
| `front3d/`      | адаптеры и проверки набора 3D-FRONT, конфигурации DPC, обучающие скрипты                         |
| `fixtures/`     | поддельный раннер для тестов договора                                                            |

Тесты `front3d/`, которым нужен генератор `front3d-pano`, без него пропускаются.
`pythonpath = ["runners"]` в `pyproject.toml` позволяет импортировать раннеры как модули.
Запускать из основной папки репозитория: в отдельном `git worktree` пакет импортируется из
основной папки, и тесты проверяют не тот код.
