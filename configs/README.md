# Конфигурации

Здесь лежат три вида файлов:

- **конфигурации запуска** — что считать: модель, набор, показатели. Запускаются командой
  `pano3dbench run --config <файл>`;
- **спецификации окружений** — как собрать окружение модели. Используются командой
  `pano3dbench env prepare --env <файл>`;
- **конфигурации самого DPC** — их читает `main.py` DeepPanoContext, а не комплекс. Их
  кладут в `configs/` клона DeepPanoContext.

Пути внутри конфигураций разрешаются относительно самого файла. `/PATH/TO/...` нужно
заменить на свои пути перед запуском.

```text
configs/
├── environments/   окружения моделей
├── protocols/      общий протокол показателей
├── demo/           проверки без GPU и данных, вместе с тестовой сценой
├── igibson/        всё для набора iGibson
└── front3d/        всё для набора 3D-FRONT
```

## `environments/` — окружения моделей

| Файл        | За что отвечает                                                                                                                                                                                                                                                                            |
|-------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `dpc.yaml`  | окружение `Pano3D` (conda) для DPC, Im3D-Pano и Total3D-Pano: клон DeepPanoContext, снятие жёстких версий, веса авторов, опорные сети torchvision, раннер `runners/dpc_runner.py` в пакетном режиме. Правка `PANO3D_CLASSES` подставляет список классов 3D-FRONT вместо 56 классов iGibson |
| `echo.yaml` | пустое окружение venv с раннером `echo_runner.py`: проверка менеджера окружений без модели                                                                                                                                                                                                 |

## `protocols/` — общий протокол

| Файл         | За что отвечает                                                                                                                                                                                                               |
|--------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `boxes.yaml` | показатели статьи для любого набора: IoU макета, mAP по сцене и по набору при ориентированном 3D-IoU 0.15, столкновения, нарушения макета с допуском 0.05, проникание. Его наследуют все конфигурации методов через `extends` |

## `demo/` — проверки без GPU и данных

Все читают одну тестовую сцену из `demo/scene/`: перечень `manifest.jsonl`, эталон
`ground-truth/`, готовое предсказание `predictions/` и пустую заглушку вместо панорамы.

| Файл              | За что отвечает                                                                                        | Как запускается     |
|-------------------|--------------------------------------------------------------------------------------------------------|---------------------|
| `smoke.json`      | показатели по готовому предсказанию; самая быстрая проверка ядра                                       | `make smoke`        |
| `echo_local.yaml` | весь путь через изолированное окружение с раннером echo                                                | `make env-demo`     |
| `dpc.yaml`        | пример запуска DPC через окружение на тестовой сцене; на нём проверяется создание скрипта для кластера | `env submit-script` |

## `igibson/` — набор iGibson

Воспроизведение по шагам — [docs/igibson.md](../docs/igibson.md).

### `igibson/protocols/`

| Файл               | За что отвечает                                                                                                                     |
|--------------------|-------------------------------------------------------------------------------------------------------------------------------------|
| `igibson_pcf.yaml` | протокол контрольной строки: mAP только по 11 классам публикаций DPC и PanoContext-Former, плюс AP по каждому классу (`ap_<класс>`) |

### `igibson/runs/` — строки статьи

У каждого метода два файла: `<метод>.yaml` запускает модель через окружение
(`model.type: dpc`, нужен вывод DPC на диске), `<метод>_rescore.yaml` пересчитывает уже
переведённые в JSON предсказания (`model.type: fixture`, без GPU). Числа у них одинаковые.

| Файл                         | Строка статьи                                                                           | Откуда предсказания                                  |
|------------------------------|-----------------------------------------------------------------------------------------|------------------------------------------------------|
| `dpc.yaml`                   | DPC@100, выпуск авторов                                                                 | `out/pano3d`                                         |
| `dpc_rescore.yaml`           | то же по готовым предсказаниям                                                          | `igibson_bench/pred`                                 |
| `dpc_s20.yaml`               | DPC@20, 20 шагов оптимизации отношений                                                  | `out/pano3d_dpc_s20`                                 |
| `dpc_s20_rescore.yaml`       | то же по готовым предсказаниям                                                          | `igibson_bench/pred_dpc_s20`                         |
| `im3d.yaml`                  | Im3D-Pano (абляция): веса DPC, оптимизация отношений выключена                          | `out/pano3d_im3d`                                    |
| `im3d_rescore.yaml`          | то же по готовым предсказаниям                                                          | `igibson_bench/pred_im3d`                            |
| `im3d_trained.yaml`          | Im3D-Pano (обученная): наша голова LDIF, без Scene-GCN                                  | `out/pano3d_im3d_trained`                            |
| `im3d_trained_rescore.yaml`  | то же по готовым предсказаниям                                                          | `igibson_bench/pred_im3d_trained`                    |
| `total3d.yaml`               | Total3D-Pano: наша голова MGN, без Scene-GCN                                            | `out/pano3d_total3d`                                 |
| `total3d_rescore.yaml`       | то же по готовым предсказаниям                                                          | `igibson_bench/pred_total3d`                         |
| `dpc_pcf.yaml`               | контрольная строка DPC@100 на 11 классах (45.21 %)                                      | `igibson_bench/pred`                                 |
| `dpc_s20_pcf.yaml`           | контрольная строка DPC@20 на 11 классах (54.26 %)                                       | `igibson_bench/pred_dpc_s20`                         |
| `shape_chamfer_rescore.yaml` | форма: Чамфер и F-мера, `normalize: canonical`; запускается дважды — для LDIF и для MGN | `igibson_bench/pred_total3d_shape` и аналог для LDIF |

Конфигурации методов наследуют `../../protocols/boxes.yaml`, контрольные строки —
`../protocols/igibson_pcf.yaml`, форма задаёт свои показатели сама.

### `igibson/dpc/` — конфигурации самого DPC

| Файл                          | За что отвечает                                                            |
|-------------------------------|----------------------------------------------------------------------------|
| `pano3d_igibson_im3d.yaml`    | вывод Im3D-Pano (обученной): ствол DPC с нашей головой LDIF, без Scene-GCN |
| `pano3d_igibson_total3d.yaml` | вывод Total3D-Pano: ствол DPC с нашей головой MGN, без Scene-GCN           |
| `ldif_igibson_scratch.yaml`   | обучение головы LDIF с нуля (веса `im3d-pano_ldif_igibson.pth`)            |
| `mgnet_igibson.yaml`          | обучение головы MGN (веса `total3d-pano_mgn_igibson.pth`)                  |

Вывод DPC@100, DPC@20 и абляции Im3D-Pano идёт по `configs/pano3d_igibson.yaml` из самого
DeepPanoContext, своей конфигурации у них нет.

## `front3d/` — набор 3D-FRONT

Воспроизведение — [docs/front3d.md](../docs/front3d.md).

| Файл                                  | За что отвечает                                                                                       |
|---------------------------------------|-------------------------------------------------------------------------------------------------------|
| `front3d_to_igibson.json`             | соответствие классов 3D-FRONT словарю iGibson для сравнения двух наборов; используется только в тесте |
| `dpc/README.md`                       | порядок шести обучений на 3D-FRONT и переменная `PANO3D_CLASSES`                                      |
| `dpc/bdb3d_estimation_front3d.yaml`   | обучение BEN (трёхмерные рамки) с нуля на сценах `dpc_scenes/`                                        |
| `dpc/ldif_front3d.yaml`               | обучение головы LDIF на предметах `objects/`                                                          |
| `dpc/mgnet_front3d.yaml`              | обучение головы MGN на предметах `objects/`                                                           |
| `dpc/relation_scene_gcn_front3d.yaml` | обучение Scene-GCN; нужны готовые веса BEN и LDIF                                                     |

Детектор и HorizonNet обучаются скриптами `training/`, своих конфигураций здесь у них нет.
Конфигурации вывода и оценки на 3D-FRONT пока есть только на кластере; их место —
`front3d/runs/`.
