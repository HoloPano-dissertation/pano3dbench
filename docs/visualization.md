# Рамки на панораме

`pano3dbench draw` рисует поверх равнопромежуточной панорамы трёхмерные рамки предметов
и макет комнаты: эталон зелёным, предсказание красным, с подписью класса (у предсказания —
ещё и балла). Им удобно проверять разметку набора и предсказания любого метода, не открывая
трёхмерный просмотрщик.

Рисованию нужен Pillow, ядро без него работает как прежде:

```bash
pip install -e '.[viz]'
```

## Команды

Один вид:

```bash
pano3dbench draw --image rgb/test/<дом>/<комната>/0.png \
    --ground-truth ground_truth/test/<дом>/<комната>/0.json \
    --prediction eval/pred_dpc/<дом>/<комната>/0.json \
    --output view.png
```

Несколько видов по перечню (`manifest.jsonl` с полями `sample_id`, `input`,
`ground_truth`), предсказания — папка `<sample_id>.json`, как у `model.type: fixture`:

```bash
pano3dbench draw --manifest eval/manifest_pred_dpc.jsonl --predictions eval/pred_dpc \
    --output artifacts/overlay_dpc --limit 20
```

| Параметр                     | Смысл                                      |
|------------------------------|--------------------------------------------|
| `--sample <id>`              | рисовать только этот вид (можно повторять) |
| `--limit N`                  | не больше N видов                          |
| `--min-score s`              | не рисовать предсказания с баллом ниже `s` |
| `--no-labels`, `--no-layout` | без подписей, без макета                   |
| `--line-width`               | толщина линий рамок (макет — на 1 тоньше)  |

Каждый файл получает в левом верхнем углу имя вида и легенду цветов.

## Как строится картинка

Рамки и макет заданы в системе камеры набора: метры, ось Z вверх, начало в камере. Точка
`(x, y, z)` переходит в пиксель панорамы `W × H` так же, как в адаптерах набора:

```text
столбец = ((0.5 + atan2(x, y) / 2π) mod 1) · W − 0.5
строка  = (0.5 − atan2(z, √(x² + y²)) / π) · H − 0.5
```

Прямое ребро рамки на панораме — кривая, поэтому каждое ребро делится на 48 отрезков,
и проецируется каждая промежуточная точка, а не только углы. Если соседние точки
оказываются у разных краёв кадра (ребро пересекает шов), линия разрывается и продолжается
с другого края.

Макет у предсказаний — осевой параллелепипед, как его и оценивает бенчмарк. Если в эталоне
есть точный контур комнаты (`metadata.layout_geometry_world.polygon` и
`metadata.camera_location_world`, так у набора 3D-FRONT), рисуется он: углы стен,
контуры пола и потолка на высотах параллелепипеда макета.

Проверка на тестовой части 3D-FRONT: у всех 35 435 видимых эталонных предметов маска из
COCO-разметки лежит внутри спроецированной рамки (медиана и 1-й процентиль — 100 %
пикселей маски); исключения — предметы вплотную к камере или над ней, где проекция рамки
перестаёт быть прямоугольником на развёртке.
